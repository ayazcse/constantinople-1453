# Methodology

## Purpose

This project treats "building a defensible number" as the core analytical work, not a
preliminary step to be hidden behind a clean chart. It documents the siege of Constantinople
(1453) and the city's transformation into Ottoman Istanbul using only claims this project could
trace to a specific, tiered source — and it keeps disagreements between sources visible rather
than silently resolving them.

## Source tiers

| Tier | Definition | Examples used here |
|------|-----------|---------------------|
| **Tier 1** | Peer-reviewed scholarship, edited primary-source translations, standard academic references | Oxford Dictionary of Byzantium; George Sphrantzes's chronicle (De Re Militari translation); Necipoglu's catalogue essay; Mehmet Oz's demographic chapter |
| **Tier 2** | Credible institutional sources not peer-reviewed in the academic sense | Encyclopaedia Britannica; UNESCO World Heritage Centre; TurkStat (TUIK); Archnet (Aga Khan / MIT) |
| **Tier 3** | Popular / secondary sources | World History Encyclopedia; travel and heritage blogs; news summaries |

Every row in every dataset carries one or more `source_id` values resolving to
`data/raw/sources.csv`, or explicitly `N/A` for a small number of general-knowledge rows
(flagged with lower confidence).

## Confidence levels

- **High** — directly stated in a Tier 1/2 source, or independently corroborated across source
  types (e.g. the ~70-ship overland transfer, confirmed by both the Oxford Dictionary of
  Byzantium and a popular synthesis).
- **Medium** — reported in a credible source without independent cross-checking, or with minor
  date/figure variation between otherwise-agreeing sources.
- **Low** — a single popular-tier source, an internally inconsistent source (see the EBSCO
  army-size example in the Source Claims Ledger), or an attribution this project could not trace.
- **Not verified** — a claim that circulates widely but that this project could not confirm in
  the sources it reviewed. Kept visible and labelled rather than deleted or invented around.

## Known, documented disagreements

The single most important artifact in this project is arguably
`data/raw/source_claims.csv` — 24 specific numeric claims (army sizes, defender counts,
wall lengths, cannon dimensions, siege duration) with every value found, its source, and a note
on why the disagreement likely exists. Examples:

- **Ottoman land army size** ranges from a contemporary chronicle figure of 200,000 (widely
  considered rhetorical) down to a modern-historian consensus range of 60,000–80,000, with one
  reference database contradicting itself between 120,000 and 160,000 in the same article.
- **Theodosian land-wall length** is reported as either 5.7 km (the main triple-wall line) or
  6.67 km (likely including the Blachernae extension) — a scope difference, not a factual one.
- **Siege duration** is reported as either 53 or 55 days depending on which start date a source
  uses (6 April vs 2 April).

## Limitations

1. Several structures in `fortifications.csv` (the Golden Horn and Marmara sea walls, the
   Blachernae extension) have no independently-sourced dimension figures at all — these are
   marked N/A rather than estimated.
2. The 1477 household census breakdown by religious/ethnic community is only partially verified:
   the Jewish figure (1,647 households) is directly sourced; the remainder is kept as an
   unverified residual rather than reproducing a commonly-circulated but unconfirmed breakdown.
3. A handful of macro-timeline rows (the Tanzimat era, the 1923 move of the capital to Ankara,
   the Suleymaniye Mosque) rely on general historical knowledge not independently re-verified by
   this project's search process, and are marked accordingly with `source_ids = N/A` and reduced
   confidence.
4. Coordinates are historical approximations for analytical purposes, not a surveyed GIS dataset.
   Only three wall gates use published GPS coordinates (cited to Turkish Archaeological News);
   everything else is labelled `Approximate` or `Schematic`.
5. This project's search process has a cutoff; if you extend it, re-verify anything
   time-sensitive (e.g. the most recent Istanbul population figures) against current TUIK data.

## Reproducing the pipeline

See the README for setup. In short: `data/raw/*.csv` are the only hand-edited files; everything
in `data/interim/`, `data/processed/`, and `public/data/` is generated by
`python scripts/run_pipeline.py` and should not be hand-edited.
